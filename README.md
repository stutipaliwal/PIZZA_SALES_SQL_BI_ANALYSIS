# 🍕 PIZZA_SALES_SQL_BI_ANALYSIS (SQL & Power BI)

## 📌 Project Overview
This project provides a comprehensive end-to-end analysis of a pizza restaurant's sales performance. Using transactional data stored in Excel, I performed data analysis and KPI aggregation using **SQL Server (T-SQL)**, and built an interactive dashboard in **Power BI** to visualize key metrics, customer ordering habits, and revenue trends.

---

## 🛠️ Tools & Technologies
* **Data Source:** Microsoft Excel (`pizza_sales.csv`)
* **Database & Querying:** SQL Server (T-SQL)
* **Data Visualization:** Microsoft Power BI (`pizza_sales_dashboard.pbix`)
* **Repository Hosting:** GitHub

---

## 📊 Key Performance Indicators (KPIs) Analyzed
From the dataset, the following key metrics were computed to evaluate business growth:

1. **Total Revenue:** Sum of all pizza order prices.
2. **Average Order Value (AOV):** Average amount spent per order.
3. **Total Pizzas Sold:** Total count of individual pizzas sold.
4. **Total Orders:** Total number of distinct orders placed.
5. **Average Pizzas Per Order:** Ratio of total pizzas sold to total distinct orders.

---

## 🔍 Key Insights & Business Questions Answered

### 1. Sales & Order Trends
* **Busiest Days & Months:** Identified peak order volumes by day of the week (`DATENAME(DW)`) and month (`DATENAME(MONTH)`).
* **Category Sales Distribution:** Evaluated percentage of total sales generated by each pizza category (e.g., Classic, Veggie, Supreme, Chicken).
* **Size Preference:** Analyzed sales contribution by pizza size (S, M, L, XL, XXL) across quarters.

### 2. Product Performance (Top & Bottom Performers)
* **By Revenue:** Top 5 and Bottom 5 pizzas based on total revenue generated.
* **By Quantity:** Top 5 and Bottom 5 pizzas based on total units sold.
* **By Orders:** Top 5 and Bottom 5 pizzas based on total distinct orders placed.

## 💻 Featured SQL Queries

Here is a look at the SQL queries executed to extract key insights:

### 🔹 High-Level KPIs
```sql
-- Total Revenue
SELECT SUM(total_price) AS Total_Revenue FROM pizza_sales;

-- Average Order Value
SELECT SUM(total_price) / COUNT(DISTINCT order_id) AS Average_Order_Value FROM pizza_sales;

-- Total Pizzas Sold
SELECT SUM(quantity) AS Total_Pizza_Sold FROM pizza_sales;

-- Total Orders
SELECT COUNT(DISTINCT order_id) AS Total_Order FROM pizza_sales;

-- Average Pizzas Per Order
SELECT CAST(CAST(SUM(quantity) AS DECIMAL(10,2)) / CAST(COUNT(DISTINCT order_id) AS DECIMAL(10,2)) AS DECIMAL(10,2)) AS Average_Pizza_Per_Order 
FROM pizza_sales;

-- Daily Trend for Total Orders
SELECT DATENAME(DW, order_date) AS Order_Day, COUNT(DISTINCT order_id) AS Total_Order 
FROM pizza_sales 
GROUP BY DATENAME(DW, order_date);

-- Monthly Trend for Total Orders (Ordered by Volume)
SELECT DATENAME(MONTH, order_date) AS Order_Month, COUNT(DISTINCT order_id) AS Total_Order 
FROM pizza_sales 
GROUP BY DATENAME(MONTH, order_date) 
ORDER BY Total_Order DESC;

-- Top 5 Pizzas by Revenue
SELECT TOP 5 pizza_name, CAST(SUM(total_price) AS DECIMAL(10,2)) AS Total_Revenue 
FROM pizza_sales 
GROUP BY pizza_name 
ORDER BY Total_Revenue DESC;

-- Top 5 Pizzas by Quantity Sold
SELECT TOP 5 pizza_name, SUM(quantity) AS Total_Quantity 
FROM pizza_sales 
GROUP BY pizza_name 
ORDER BY Total_Quantity DESC;
